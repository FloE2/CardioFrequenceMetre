Aucun capteur pour l'instant Allumez les capteurs, puis cliquez sur « Ajouter un capteur » une fois pour chacun.

Pour ajouter un capteur, choisissez son nom (« Polar Sense … ») dans la fenêtre du navigateur. Le numéro est gravé au dos du capteur : notez-le sur chaque brassard pour savoir qui porte quoi.

Cliquez sur « Prénom » dans une carte pour indiquer l'élève. Le prénom reste associé tant que le capteur est allumé.
